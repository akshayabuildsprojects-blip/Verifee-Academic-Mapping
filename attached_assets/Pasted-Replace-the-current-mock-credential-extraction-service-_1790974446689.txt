Extract only information actually supported by the document:

- institution name
- country, if identifiable from the document
- degree / qualification
- programme or field of study
- graduation date, if present
- cumulative GPA, if present
- credit/unit system, if identifiable
- course code
- course title
- credits / academic units
- grade

      {

Validate the AI response before allowing the application to continue.

If information cannot be determined, return null rather than inventing it.

IMPORTANT VERIFICATION RULE

A normal uploaded PDF is not digitally verified simply because Verifee successfully reads it.

For PDF uploads, Step 2 should display:

Verification status: Digital verification unavailable

and separately:

Academic interpretation: Available

Verifee may identify the institution from the document, but this must not be presented as proof that the transcript is authentic.

Do not use terms such as:
- Verified
- Authenticated
- Officially validated

for an ordinary PDF.
