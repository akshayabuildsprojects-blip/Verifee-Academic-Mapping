Improve the Step 4 Academic Mapping user experience without changing the existing mapping logic, evidence retrieval, AI reasoning, or result schema.

The mapping itself is working correctly. This task is only to improve progress visibility and how results are displayed.

--------------------------------------------------
1. SHOW LIVE MAPPING PROGRESS
--------------------------------------------------

While academic mapping is running, show how many target requirements have completed.

Example for a program with 4 requirements:

Mapping academic requirements...

2 of 4 requirements mapped
Still in progress

Display:
- current completed count
- total requirement count
- existing progress/loading indicator

Update the count immediately whenever one requirement finishes.

Examples:

0 of 4 requirements mapped
1 of 4 requirements mapped
2 of 4 requirements mapped
3 of 4 requirements mapped
4 of 4 requirements mapped

When all requirements finish, change the loading state to:

Academic mapping complete

Do not use fake timed progress.

The count must reflect actual completed mapping results.

--------------------------------------------------
2. PRESERVE PROGRESSIVE RESULTS
--------------------------------------------------

The application currently displays mapping results progressively as they complete.

Preserve this behavior.

Do NOT wait for all requirements to finish before showing results.

As each requirement finishes:

- update the completed count
- immediately add that requirement's result to the results area
- continue processing the remaining requirements

Example:

2 of 4 requirements mapped
Still in progress

[Completed result 1]
[Completed result 2]

Remaining requirements continue processing.

--------------------------------------------------

As results arrive progressively:

- automatically expand the newest completed result

The user can freely open and close any card.

Avoid having all cards expanded at once because this makes long reports difficult to scan.
