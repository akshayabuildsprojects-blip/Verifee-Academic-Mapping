==================================================
8. DUPLICATE REPORT CHECK
==================================================

Add a simple duplicate check before saving a new report.

A report should be considered an existing equivalent report if the demo report list already contains the same:

- source institution
- source academic program/discipline
- target institution
- target program

If a matching report already exists, do not silently create another identical report.

Show:

A Verifee report for this academic record and target program already exists.

Actions:

View Existing Report
Continue Anyway

Continue Anyway may create another report if the user deliberately chooses to.

This is only a basic MVP duplicate check.

Do NOT build complicated record-matching logic.

==================================================
9. DUPLICATE FILE CHECK
==================================================

Add a lightweight client-side duplicate-upload check where practical.

During the current browser session, keep track of uploaded credential files.

If the exact same file is selected again during the same session, show a non-blocking message:

This credential has already been uploaded in this demo session.

Actions:

Continue
View Existing Report

Do not perform external identity matching.
Do not build a document database.
Do not use AI for duplicate detection.

Keep this extremely simple.
